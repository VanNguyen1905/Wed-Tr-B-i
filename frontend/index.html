Đăng game bằng Terminal — không cần Storage/Billing

Trong PowerShell tại thư mục dự án, chạy lệnh sau với đường dẫn file HTML thực tế:

.\PUBLISH-GAME.ps1 -File "D:\Games\tro-choi.html" -Title "Tên trò chơi" -Category "Đố vui"

Chỉ chủ dự án có quyền triển khai mới đăng được file. Nút “Ẩn” dưới đây chỉ ẩn khỏi danh mục; file có URL trực tiếp vẫn truy cập được.
